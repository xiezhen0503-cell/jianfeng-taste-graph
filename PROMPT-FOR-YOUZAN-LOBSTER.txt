请学习并复刻这个 GitHub 仓库中的“尖锋 Taste Graph”移动端 H5。

先阅读根目录 README.md 和 HANDOFF.md，再读取 source/ 目录中的完整源码。不要反编译 site/_next，也不要使用仓库中的历史 zip 或 part 文件。source/ 才是当前版本；site/ 是已经构建好的静态站点。

需要复刻时，请保留：首次访问测试邀请、15 道口味测试、10 维 Taste Graph、16 种口味称号、尖锋商品推荐、真实图片和短视频、动态单餐搭配、热量区间、3 天/7 天计划、首购/加购/复购权益、好友合拍、厨房挑战及六项底部导航。

项目没有后端、数据库或 API Key，用户状态暂存在 localStorage。正式接入有赞时，再把登录、订单、优惠券核销、商品库存价格、点赞和排行榜替换为真实接口；不要把前端本地状态当成真实交易结果。

如果只需部署，直接把 site/ 作为静态网站根目录发布，避免重新安装依赖和构建。完成后请返回公网 URL、复刻或部署方式、验收结果、接入有赞仍需补齐的接口，以及发现的问题。
